## 2026-07-14 — Сверка индикатора v7 с движком v5, выпуск v7.1

### Что сделано
Написана эталонная реализация правил v5 (`engine/reference_v5.py`):
пивоты/метки/цепочка решения — по документации, триггеры — из колонки CSV.
Прогон по золоту 1H (52 518 баров, 9 416 триггеров).

### Результат сверки — эталон воспроизведён
| Метрика | engine_v5 (эталон) | reference_v5 |
|---|---|---|
| v5: сделок / итог | 939 / +53.2R | 939 / +53.1R |
| v5: train / test | +31.2 / +22.0 | +31.1 / +22.0 |
| v5 бакеты LL/LH/HL/HH | +42.3/+24.2/-0.6/-12.6 | +42.3/+24.1/-0.7/-12.6 |
| v4: сделок / итог | 1246 / -38.5R | 1246 / -38.6R |
| Порог P80 | ≈0.32% | 0.317% |

Расхождения — только округление. Значит зафиксированы точные семантики движка:
- пивот 2/2 строгий (равенство соседей ломает пивот), подтверждение +2 бара;
- метка при равной цене пивотов НЕ создаётся;
- метки, подтверждённые НА триггерном баре, входят в рабочую пятёрку;
- SL и TP в одном баре = SL (консервативно); резолв с бара i+1;
- перцентиль — по всей истории (lookahead), numpy linear interpolation;
- движок НЕ блокирует перекрывающиеся сделки (939 включают оверлапы).

### Найденные расхождения индикатора v7 с движком (квантифицировано)
1. «Одна позиция» вкл. по умолчанию → 723 входа вместо 939 (−23% жёлтых точек).
   Любопытно: сама блокировка улучшает итог (+64.1R против +53.1R), но это
   ДРУГАЯ система — непроверенная. В очередь проверок, не в правила.
2. Растущее окно перцентиля → 863 сделки вместо 939 (ранняя история — другой порог).
3. Оба вместе (дефолты v7): 673 входа вместо 939 (−28%).
4. Одна виртуальная позиция в коде: при оверлапе вторая сделка затирала
   первую, её SL/TP не отрисовывался.
5. Лимит TradingView 500 линий: 939 сделок × 3 линии = 2817 → старые молча
   стирались (левая часть истории «лысая»).
6. Мелочь: offset у HL/LH в plotshape перепутаны (rightLenH↔rightLenL);
   при дефолте 2/2 невидимо.

## 2026-07-14 (вечер-2) — Обязательные проверки v5: смешанный вердикт

Скрипт: engine/exp_v5_checks.py. Все числа из выполненных прогонов.

### 1. Контроль случайностью пакета запретов — ПРОЙДЕН
10000 симуляций выброса 307 случайных сделок из v4 (1246, -38.5R):
медиана -28.3R, 5-95% [-82.8, +25.3], максимум +82.0R.
Пакет запретов: +53.2R, **p-value 0.0054**. Запреты — не случайность:
лучше 99.5% случайных выбросов. (Для сравнения: «одна позиция» имела p=0.21.)

### 2. Помесячная развёртка — ГЛАВНАЯ СЛАБОСТЬ ПОДТВЕРДИЛАСЬ
108 месяцев со сделками: 48 плюсовых, 60 минусовых.
Топ-3 месяца: 2023-12 +28.5R, 2026-03 +20.0R, 2023-07 +17.6R.
**Без топ-3 месяцев итог 9 лет = -12.9R.** Опасение из доков («нет ли 2-3
месяцев, тянущих весь плюс») — реальность: тянут.

### 3. Walk-forward
а) Годовая развёртка v5: 7 из 10 лет плюс, но 2024 = **-40.8R** (при 1R=$250
   это -$10 200 за год), 2020-21 подряд минусовые (-13.8, -5.7).
б) Честный порог (растущее окно вместо полной истории — единственный
   подгоняемый параметр): 863 сделки, +34.9R, те же 7/10 плюсовых лет.
   Эдж не исчезает без подглядывания, но худеет: 53.2 -> 34.9R.

### 4. Каждый запрет на обеих половинах — ПОДТВЕРЖДЕНО
LL>HH: train -22.7 / test -16.2 | LL>LH>HL: -17.0 / -6.6 |
HH>LH: -3.0 / -16.1 | HH>LL>LL: -8.8 / -1.5. Все минусовые на обеих.

### ЧЕСТНЫЙ ИТОГ
Запреты v5 — настоящий сигнал (p=0.005, устойчивы по половинам).
Но эдж ТОНКИЙ и КОМКОВАТЫЙ: весь плюс 9 лет держится на 3 месяцах,
бывает год -40R, а без lookahead-порога итог -35%. Статус «ИССЛЕДОВАНИЕ,
не готовая система» подтверждён данными: торговать это в текущем виде
нельзя — просадку -40R за год при WR 20% не переживёт ни счёт
проп-челленджа, ни психика. Направление живое, но нужен либо фильтр
режима рынка (2020-21 и 2024 съедают всё), либо признание, что эдж
проявляется эпизодами, и правило, когда систему ВЫКЛЮЧАТЬ.

## 2026-07-14 (вечер) — Кандидат «одна позиция»: ПРОВЕРКУ НЕ ПРОШЁЛ

Наблюдение выглядело привлекательно: блокировка перекрывающихся сделок
даёт 723 сделки / +64.2R против эталона 939 / +53.2R. Проверки
(engine/exp_one_pos.py):

1. **Train/test — провал.** Train (<2022): +3.2R. Test (>=2022): +61.0R.
   Весь «эффект» живёт в одной эпохе; эталон v5 сбалансирован (+31/+22).
2. **Контроль случайностью — провал.** 10000 симуляций выброса 216
   случайных сделок: медиана +41.6R, 5-95% [-6.6, +87.7]. Блокировка
   (+64.2R) внутри диапазона, p-value 0.213 — от случайного удаления
   не отличима.
3. **Помесячно.** Суммарный прирост +10.9R; топ-3 месяца дают 201% —
   эффект концентрированный, знакопеременный шум.

ВЕРДИКТ: в ЗАКРЫТЫЕ ТУПИКИ. «Одна позиция» остаётся опцией отображения
в индикаторе (для ручной торговли одна позиция — правило риск-каркаса,
не эджа), но статистическим правилом НЕ является. В v7.1 по умолчанию
выключена — график продолжает соответствовать эталону 939.

Деталь для честности: чувствительность к границе (вход в бар выхода
разрешён/запрещён) меняет итог 64.2↔66.5R — ещё один признак хрупкости.
