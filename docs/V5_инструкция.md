# ДВИЖОК v5 — ПОЛНАЯ ИНСТРУКЦИЯ
Инструмент: золото (XAU/USD), таймфрейм 1H. Статус: ИССЛЕДОВАНИЕ (не готовая система).
Риск: 1R = $250 на сделку. Одна позиция за раз.

==================================================================
## ЧАСТЬ 1. БАЗОВЫЕ ПОНЯТИЯ
==================================================================

### 1.1 Пивот (быстрый, 2/2)
Максимум-пивот: свеча, чей high выше high двух свечей слева И двух справа.
Минимум-пивот: low ниже low двух слева и двух справа.
Пивот ПОДТВЕРЖДАЕТСЯ через 2 бара после своей свечи (нужны 2 правые свечи).
До подтверждения пивот НЕ существует для решений.

### 1.2 Метки структуры
Каждый новый подтверждённый пивот сравнивается с ПРЕДЫДУЩИМ пивотом того же типа:
- HH = максимум ВЫШЕ предыдущего максимума
- LH = максимум НИЖЕ предыдущего максимума
- HL = минимум ВЫШЕ предыдущего минимума
- LL = минимум НИЖЕ предыдущего минимума
Рабочая последовательность = 5 последних подтверждённых меток.

### 1.3 Жёлтая точка (триггерная свеча)
Свеча, чья форма совпадает с одним из 40 шаблонов (доджи / спиннинг-топы и родня).
Форма = три доли диапазона свечи: тело %, верхний фитиль %, нижний фитиль %.
Совпадение = все три доли в пределах ±4 п.п. от шаблона.
Частота: ~18% всех свечей, ~20 точек в неделю на золоте.
Жёлтая точка = ТОЧКА ВОЗМОЖНОСТИ, не приказ входить. Вход даёт ~1 точка из 10.

==================================================================
## ЧАСТЬ 2. ЦЕПОЧКА РЕШЕНИЯ (на каждой жёлтой точке, по порядку)
==================================================================
Любой шаг может дать ПРОПУСК — тогда дальше не идём.

### ШАГ 1. НАПРАВЛЕНИЕ
По ПОСЛЕДНЕЙ подтверждённой метке:
- HL → ЛОНГ (откат в росте)
- LL → ЛОНГ (разворот от низов)
- LH → ШОРТ (откат в падении)
- HH → ШОРТ (разворот от вершины)

### ШАГ 2. ЗАМОРОЗКА СВЕЖЕГО ЭКСТРЕМУМА
Если последняя метка LL или HH и она подтвердилась 0-1 бар назад → ПРОПУСК.
Смысл: разворотный вход на только что созревшем экстремуме — слишком рано,
цена ещё в импульсе.

### ШАГ 3. РАЗМЕР ТРИГГЕРНОЙ СВЕЧИ
Размер = (high − low) / close × 100.
Если размер выше 80-го перцентиля распределения размеров ВСЕХ триггерных
свечей истории (на золоте ≈ 0.32% от цены) → ПРОПУСК.
Смысл: аномально крупная «нерешительная» свеча — это не пауза, а волатильный
выброс; глазом — «жёлтая точка заметно жирнее обычных».

### ШАГ 4. СОГЛАСОВАННОСТЬ ПЯТИ МЕТОК
Считаем в 5 последних метках: ВВЕРХ = количество HH+HL, ВНИЗ = LH+LL.
Проверка действует, только если внутри пятёрки НЕТ слома (нет пары HH→LL
или LL→HL подряд):
- ШОРТ от HH при ВВЕРХ ≥ 3 из 5 → ПРОПУСК
- ШОРТ от LH при ВВЕРХ ≥ 4 из 5 → ПРОПУСК
- ЛОНГ (любой) при ВНИЗ ≥ 4 из 5 → ПРОПУСК
Смысл: не вставать против явного тренда. Для шорта от HH порог строже (3/5),
потому что шорт вершины в бычьей структуре — исторически худшая сделка.

### ШАГ 5. СВЕЖИЙ СЛОМ
Если две ПОСЛЕДНИЕ метки образуют слом: HH→LL или LL→HL → ПРОПУСК.
Смысл: структура только что сломалась — ждать подтверждающую метку в новую
сторону, не входить в момент неопределённости.

### ШАГ 6. ЗАПРЕТЫ СТРУКТУР (ядро v5)
Смотрим ХВОСТ последовательности меток (самые свежие в конце):

| Вход        | Запрещённый хвост | Смысл запрета                                  |
|-------------|-------------------|------------------------------------------------|
| ШОРТ от HH  | …LL > HH          | HH сразу после LL = отскок из низов, V-вынос.   |
|             |                   | Шорт первой вершины выноса — против импульса.   |
| ШОРТ от LH  | …HH > LH          | LH сразу после HH без LL между = слом вершины   |
|             |                   | НЕ подтверждён. Шорт преждевременен.            |
| ЛОНГ от HL  | …LL > LH > HL     | Между LL и HL стоит LH = даунтренд ЖИВ.         |
|             |                   | HL — лишь отскок внутри падения.                |
| ЛОНГ от LL  | …HH > LL > LL     | Два LL сразу после вершины HH = свежий обвал.   |
|             |                   | Лонг = ловля падающего ножа.                    |

Общий смысл всех четырёх: НЕ входить против живого тренда и НЕ входить
на неподтверждённом развороте. (Каждый запрет по отдельности минусовый
на обеих половинах истории золота.)

### ШАГ 7. СТОП
ЛОНГ: стоп = low триггерной свечи × 0.999 (на 0.1% ниже).
ШОРТ: стоп = high триггерной свечи × 1.001 (на 0.1% выше).
Если стоп оказался не по ту сторону от входа → ПРОПУСК (техническая защита).
Риск сделки = |вход − стоп| = 1R = $250 (размер позиции подгоняется под это).

### ШАГ 8. МАГНИТ И ТЕЙК
Кандидаты: из 5 последних меток берём метки СТОРОНЫ ТЕЙКА
(для лонга — максимумы HH/LH, для шорта — минимумы LL/HL),
находящиеся ДАЛЬШЕ входа по направлению сделки.
Перебираем от БЛИЖНЕЙ к дальней; ТЕЙК = первая метка с RR ≥ 3
(RR = расстояние до метки / риск).
Ближние метки с RR < 3 ПЕРЕПРЫГИВАЮТСЯ (проверено: вариант «только
ближайшая или ничего» статистически хуже).
Нет ни одной метки с RR ≥ 3 → ПРОПУСК.

### ШАГ 9. ВХОД И СОПРОВОЖДЕНИЕ
Вход: по close триггерной свечи (рыночный на закрытии).
Тейк = магнит из шага 8. Стоп из шага 7. НЕ двигаются.
Одна позиция: пока сделка не закрыта, новые сигналы игнорируются.
Стоп сработал = сделка закрыта. Пересиживание запрещено (просадки
«ложных» стопов — медиана 5.5R — пересидеть невозможно, проверено).

==================================================================
## ЧАСТЬ 3. ПАРАМЕТРЫ (сводно)
==================================================================
Пивот: 2/2, подтверждение через 2 бара.
Рабочее окно: 5 последних меток.
Заморозка: лаг ≤ 1 бара для LL/HH.
Размер: 80-й перцентиль всех триггерных (~0.32% на золоте).
Согласованность: 3/5 для шорта от HH; 4/5 для остального; только без слома в пятёрке.
Запреты хвостов: LL>HH | HH>LH | LL>LH>HL | HH>LL>LL.
Стоп: за триггерной свечой ±0.1%. Тейк: первый магнит с RR≥3 (с перепрыгиванием).
Риск: 1R = $250. Одна позиция.

## ЧАСТЬ 5. СТАТУС ПРОВЕРОК — ЧЕСТНО
==================================================================
СДЕЛАНО:
- Train/test на золоте: плюс на обеих половинах (+31.2 / +22.0).
- Каждый запрет по отдельности минусовый на обеих половинах.
НЕ СДЕЛАНО (обязательные проверки до любой торговли):
- Контроль случайностью пакета запретов.
- Помесячная развёртка v5 (нет ли 2-3 месяцев, тянущих весь плюс).
- Walk-forward.
ВАЖНО: на BTC и серебре пакет НЕ работает (BTC test ухудшился, серебро
стало хуже). v5 — правила ЗОЛОТА, переносимость не доказана.

## ПРАВИЛА МЫШЛЕНИЯ
- Вход определяется В МОМЕНТЕ по цепочке шагов. Исход сделки не оправдывает
  и не осуждает вход («цена потом пошла куда надо» — ловушка ретроспективы).
- 9 из 10 жёлтых точек — пропуск. Пропуск = правильная работа системы.
- Это исследовательская версия. Правила могут измениться по результатам проверок.
